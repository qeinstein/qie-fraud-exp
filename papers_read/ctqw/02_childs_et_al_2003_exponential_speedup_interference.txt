1. CORE MATHEMATICAL MECHANISM
--------------------------------------------------------------------------------
This historic paper provides the first rigorous mathematical proof of an
exponential separation between a continuous-time quantum walk and any classical
algorithm on a graph problem (the "glued trees" problem).

The graph consists of two balanced binary trees of depth n glued together at
their leaves by a cycle or random matching. 
- Input: ENTRANCE node (root of tree 1)
- Target: EXIT node (root of tree 2)
- Total nodes: N = 2^{n+2} - 2

Classical Difficulty:
Any classical randomized walk starting at ENTRANCE moves toward the center with
drift, but once at the glued boundary, it gets hopelessly trapped in the vast
number of exponentially proliferating paths (2^n leaves). The probability of
hitting the EXIT node before getting lost is bounded by 2^{-Omega(n)}.

Quantum Solution via Symmetry & Subspace Reduction:
By grouping nodes into column subspaces |col j> (where col j contains all nodes
at distance j from the entrance), the graph collapses into an effective
1-dimensional chain of length 2n+1 with transition matrix:
    H_{j, j+1} = -sqrt(2)  (for 0 <= j < n - 1)
    H_{n, n+1} = -2
    H_{j, j+1} = -sqrt(2)  (for n + 1 <= j < 2n)

Because the quantum walk evolves unitarily in this invariant subspace without
dissipation, probability flows across the entire glued structure in polynomial
time t = O(n), achieving a transition probability:
    P_{ENTRANCE -> EXIT}(t) = Omega(1 / n^3) >= poly(1/log N)
yielding an exponential speedup over classical O(2^n).


2. WHY CLASSICAL SYSTEMS FAIL ON THIS DYNAMIC
--------------------------------------------------------------------------------
The glued-trees topology is an exact mirror of adversarial financial layering:
A central attacker sends stolen money down a branching tree of mules (the first
tree). The mules shuffle funds among themselves (the glued center), and then the
funds are systematically gathered back into target exit nodes (the second tree).

Classical models fail because:
1. Classical Random Walk (PageRank/Personalized PageRank): The diffusion entropy
   surges exponentially in the middle layer. The stationary distribution spreads
   flatly across all 2^n intermediate nodes: p_v ~ 1 / (2^n). It is mathematically
   blind to whether the funds are re-aggregating into an exit sink or dispersing
   into general commerce.
2. Classical Graph Neural Networks: Over-smoothing blurs node embeddings at the
   center layer; message passing averages features into uniform noise.


3. DIRECT VALUE & FORMULATION FOR OUR PROJECT (MONEY-MULE DETECTION)
--------------------------------------------------------------------------------
Childs et al. proves that quantum interference allows a walker to cut through
exponential middle-layer bottlenecks and detect the existence of an EXIT sink.

Takeaway for qia_engine.py:
1. "Glued-Ring Coherence Indicator":
   When evaluating a candidate transaction subgraph G_sub, compute the propagation
   profile from suspected source nodes to suspected cash-out sinks across a
   normalized time window t in [1.0, 5.0].
2. If the graph is a random acyclic dispersal (legitimate payments to independent
   merchants), the quantum transition probability to any single node remains
   diffuse: max_v P_{u -> v}(t) <= epsilon.
3. If the graph contains a reconvergent mule ring (glued fan-in structure),
   quantum constructive interference creates a sharp probability peak at the
   sink node v_sink:
       Coherence_Gain = max_t P_{u -> v_sink}(t) / (1 / |V|) >> 1
   This serves as an invariant scalar feature separating mule sinks from normal
   merchants.

```python
import numpy as np

def compute_glued_sink_coherence(H: np.ndarray, source_idx: int, t_steps: list) -> np.ndarray:
    """
    Computes time-resolved constructive interference peaks at all nodes
    originating from source_idx, identifying sink nodes that concentrate probability.
    """
    w, V = np.linalg.eigh(H)
    N = H.shape[0]
    peak_probabilities = np.zeros(N)
    
    for t in t_steps:
        # State vector |psi(t)> = V diag(e^{-i w t}) V^\dagger |source>
        # |source> is one-hot vector at source_idx -> source column of V^\dagger
        psi_t = V @ (np.exp(-1j * w * t) * V[source_idx, :].conj())
        probs = np.abs(psi_t) ** 2
        peak_probabilities = np.maximum(peak_probabilities, probs)
        
    # Relative interference gain over uniform baseline
    coherence_gain = peak_probabilities * N
    return coherence_gain
```
