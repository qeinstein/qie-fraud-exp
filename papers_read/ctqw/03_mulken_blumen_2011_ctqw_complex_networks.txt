1. CORE MATHEMATICAL MECHANISM
--------------------------------------------------------------------------------
This comprehensive 51-page review is the authoritative reference for CTQWs
on complex topologies (small-world, scale-free, Cayley trees, and random graphs).

Key Formulations Established:
1. Hamiltonian Choice:
   The walk can be driven by either the adjacency matrix A or the graph Laplacian L:
       H = -gamma * A   OR   H = gamma * L = gamma * (D - A)
   where gamma is the transmission/tunneling rate. The paper details how the
   Laplacian preserves the continuity equation (probability conservation) across
   irregular networks with inhomogeneous node degrees.

2. Return Probability (Self-Interference):
   The probability that a walker starting at node k returns to node k at time t:
       alpha_{k,k}(t) = |<k| exp(-i * H * t) |k>|^2 = |sum_n |<k|phi_n>|^2 exp(-i * E_n * t)|^2
   where E_n and |phi_n> are the eigenvalues and orthonormal eigenvectors of H.
   This quantity measures coherent trapping, localization, and topological recurrence.

3. Long-Time Average Transition Probability (Limiting Distribution):
   Unlike classical walks that converge to stationary state pi_k = d_k / (2|E|),
   quantum walks do not converge due to unitary reversibility. Instead, their
   infinite-time Cesàro mean is evaluated:
       chi_{k,j} = lim_{T -> infty} (1/T) int_0^T P_{k -> j}(t) dt
                 = sum_{E_n = E_m} |<k|phi_n><phi_n|j><j|phi_m><phi_m|k>|
   For non-degenerate spectra, this simplifies to:
       chi_{k,j} = sum_n |<k|phi_n>|^2 |<j|phi_n>|^2
   This time-averaged matrix contains pure topological memory of the graph!


2. WHY CLASSICAL SYSTEMS FAIL ON THIS DYNAMIC
--------------------------------------------------------------------------------
1. Memory Loss via Markovian Forgetfulness:
   A classical random walk's stationary distribution depends strictly on local
   degree: pi_j = d_j / sum d_i. It completely forgets the global network
   geometry, path length distribution, and community structures.
2. Equal Return Trapping:
   In classical random walks, return probability decays smoothly:
   p_{k,k}(t) ~ t^{-d/2}. In complex networks, high-degree hubs merely act as
   entropic attractors.
   In quantum walks, the return probability alpha_{k,k}(t) exhibits rapid coherent
   oscillations and destructive interference that reveal topological loops,
   cycles, and localized sub-structures that classical diffusion flattens.


3. DIRECT VALUE & FORMULATION FOR OUR PROJECT (MONEY-MULE DETECTION)
--------------------------------------------------------------------------------
Mülken & Blumen provide the exact mathematical toolkit for node-level feature
extraction in fraud detection:

1. Node Return Probability Profile:
   For every account node u in a transaction subgraph, evaluate alpha_{u,u}(t)
   at discrete time scales t in {0.5, 1.0, 2.0, 4.0}.
   - In money mule networks, cyclic routing (washing funds between 2-3 colluding
     accounts) creates high return amplitudes alpha_{u,u}(t) due to phase alignment.
   - Legitimate transit nodes exhibit immediate phase dispersion and near-zero
     return probability.

2. Quantum Limiting Matrix Chi (Topological Memory):
   The matrix Chi = (chi_{k,j}) provides a dense, unnormalized topological
   similarity kernel between all account pairs without requiring GNN message
   passing:
       chi_{k,j} = sum_n (V_{k,n}^2 * V_{j,n}^2)
   where V is the eigenvector matrix of H.
   This can be computed in closed form via standard numpy eigendecomposition
   in <2 milliseconds for subgraphs of 50 nodes!

```python
import numpy as np

def compute_quantum_limiting_distribution(H: np.ndarray) -> np.ndarray:
    """
    Computes Mülken-Blumen infinite-time average transition probability Chi
    in closed form from the eigenspectrum of H.
    Chi[k, j] = sum_n |<k|phi_n>|^2 |<j|phi_n>|^2
    Complexity: O(N^3) for eigendecomposition, O(N^2) for Chi computation.
    """
    w, V = np.linalg.eigh(H)
    # V_sq[k, n] = |V[k, n]|^2
    V_sq = np.abs(V) ** 2
    # Chi = V_sq @ V_sq.T  (matrix product of node projection weights)
    Chi = V_sq @ V_sq.T
    return Chi

def compute_return_probabilities(H: np.ndarray, t_values: list) -> np.ndarray:
    """
    Computes return probability alpha_{k,k}(t) for all nodes across given times.
    Returns: (len(t_values), N) array
    """
    w, V = np.linalg.eigh(H)
    V_sq = np.abs(V) ** 2
    returns = []
    for t in t_values:
        # amplitude_k = sum_n |V_{k,n}|^2 * exp(-i * w_n * t)
        amp = V_sq @ np.exp(-1j * w * t)
        prob = np.abs(amp) ** 2
        returns.append(prob)
    return np.array(returns)
```
