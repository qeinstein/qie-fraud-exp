1. CORE MATHEMATICAL MECHANISM
--------------------------------------------------------------------------------
This breakthrough paper solves the fundamental problem of how to represent
directed graphs (digraphs) in continuous-time quantum walks while preserving
unitarity and self-adjointness of the Hamiltonian.

Standard Graph Walk: Real symmetric adjacency A implies time-reversal symmetry:
    H^* = H  =>  P_{j -> k}(t) = P_{k -> j}(t)
This means a standard quantum walk cannot distinguish between money flowing from
Victim -> Mule vs. Mule -> Victim!

The Solution: Complex Hermitian Hamiltonian Breaking Time-Reversal Symmetry
The authors introduce complex phase factors on directed edges (chiral quantum walk):
    H_{j, k} = A_{jk} * exp(i * phi_{jk})
    where phi_{jk} = -phi_{kj} to ensure H = H^\dagger (Hermiticity).

For an unweighted directed graph with adjacency A (where A_{jk} = 1 if edge j -> k
exists and 0 otherwise), the canonical Hamiltonian is constructed as:
    H = A_s + i * gamma * (A - A^T)
where:
    A_s = (A + A^T) / 2  (symmetrized undirected skeleton)
    (A - A^T) is skew-symmetric (imaginary directed flow component)
    gamma is the chirality / directional coupling parameter.

Because H is complex Hermitian:
1. All eigenvalues lambda_n of H remain strictly real (guaranteeing physical stability).
2. Time-evolution operator U(t) = exp(-i * H * t) is strictly unitary: U^\dagger U = I.
3. Time-reversal symmetry is broken:
       P_{j -> k}(t) != P_{k -> j}(t)
4. Quantum transport efficiency along the directed path is dramatically enhanced
   over the reverse direction.

import numpy as np

def construct_hermitian_hamiltonian(adj_directed: np.ndarray, gamma: float = 1.0) -> np.ndarray:
    """
    Constructs Zimborás-Faccin-Biamonte Hermitian Hamiltonian for directed graphs:
    H = A_s + 1j * gamma * (A - A^T)
    where A_s = (A + A^T) / 2
    """
    A = adj_directed.astype(np.float64)
    A_s = 0.5 * (A + A.T)
    A_skew = A - A.T
    H = A_s + 1j * gamma * A_skew
    
    # Verify Hermiticity: H == H^\dagger
    assert np.allclose(H, H.conj().T), "Hamiltonian must be Hermitian!"
    return H

def compute_chiral_directional_flux(H: np.ndarray, t: float) -> np.ndarray:
    """
    Computes asymmetric directional flux matrix:
    Flux[u, v] = P_{u -> v}(t) - P_{v -> u}(t)
    """
    w, V = np.linalg.eigh(H)
    U_t = V @ np.diag(np.exp(-1j * w * t)) @ V.conj().T
    P_t = np.abs(U_t) ** 2
    flux_matrix = P_t.T - P_t  # P_{u->v} - P_{v->u}
    return flux_matrix
