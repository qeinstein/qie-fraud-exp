1. CORE MATHEMATICAL MECHANISM
--------------------------------------------------------------------------------
This paper introduces an information-theoretic framework for measuring structural
similarity between graphs using Continuous-Time Quantum Walks (CTQWs) and the
Quantum Jensen-Shannon Divergence (QJSD).

Mathematical Formulation:
1. Graph Density Matrix:
   Given a graph G with normalized graph Laplacian L, the thermal density matrix
   at inverse temperature beta is defined by the Gibbs state:
       rho(beta) = exp(-beta * L) / Tr[exp(-beta * L)]
   where rho(beta) is Hermitian, positive semi-definite, and has unit trace (Tr[rho] = 1).
   Alternatively, under unitary CTQW evolution from an initial state rho_0, the
   time-dependent density matrix is:
       rho(t) = U(t) rho_0 U(t)^\dagger = exp(-i L t) rho_0 exp(i L t)

2. Von Neumann Graph Entropy:
   The information entropy of the graph state is given by the Von Neumann entropy:
       S(rho) = -Tr[rho * log_2(rho)] = -sum_n lambda_n * log_2(lambda_n)
   where lambda_n are the eigenvalues of rho.

3. Quantum Jensen-Shannon Divergence (QJSD):
   To compare two graph states rho_1 and rho_2 (or compare a perturbed transaction
   graph against a baseline legitimate graph):
       QJSD(rho_1, rho_2) = S((rho_1 + rho_2) / 2) - 0.5 * S(rho_1) - 0.5 * S(rho_2)
   Properties of QJSD:
   - Symmetrical: QJSD(rho_1, rho_2) = QJSD(rho_2, rho_1)
   - Bounded: 0 <= QJSD(rho_1, rho_2) <= 1 (log base 2)
   - The square root sqrt(QJSD) is a true mathematical metric on quantum state space!


2. WHY CLASSICAL SYSTEMS FAIL ON THIS DYNAMIC
--------------------------------------------------------------------------------
1. Graph Edit Distance Intractability:
   Measuring graph similarity or anomalous structure via classical Graph Edit
   Distance (GED) or subgraph isomorphism is NP-hard, making real-time streaming
   scoring impossible.
2. Classical KL-Divergence Asymmetry & Divergence:
   Classical Kullback-Leibler (KL) divergence on random walk transition matrices
   is asymmetric and diverges to infinity when support sets do not overlap
   (common when comparing sparse transaction subgraphs).
   QJSD is strictly bounded in [0, 1] and remains smooth even on disjoint graphs.


3. DIRECT VALUE & FORMULATION FOR OUR PROJECT (MONEY-MULE DETECTION)
--------------------------------------------------------------------------------
Rossi et al.'s formulation provides our QIA engine with two powerful features:

1. Von Neumann Subgraph Entropy as an Anomaly Indicator:
   - Legitimate retail networks (diverse, balanced commerce) have high Von
     Neumann entropy: S(rho) is high because eigen-modes are distributed.
   - Money mule syndicates (rigid, low-entropy directed funnels and star-like
     hubs) exhibit sharp drops in Von Neumann entropy: S(rho) is compressed.
   - We extract S(rho) directly as a graph-level scalar feature.

2. QJSD Subgraph Anomaly Score:
   We can maintain a baseline reference density matrix rho_{baseline} representing
   typical legitimate transaction flow topology. When a high-velocity incident
   occurs, we compute the local subgraph's density matrix rho_{local} and evaluate:
       Anomaly_Score = sqrt(QJSD(rho_{local}, rho_{baseline}))
   This provides an anomaly score in [0.0, 1.0] in closed spectral form!

```python
import numpy as np
import scipy.linalg

def compute_gibbs_density_matrix(L: np.ndarray, beta: float = 1.0) -> np.ndarray:
    """
    Computes Gibbs density matrix: rho = exp(-beta * L) / Tr[exp(-beta * L)]
    """
    w, V = np.linalg.eigh(L)
    exp_w = np.exp(-beta * w)
    trace = np.sum(exp_w)
    if trace == 0:
        return np.eye(L.shape[0]) / L.shape[0]
    rho = V @ np.diag(exp_w / trace) @ V.conj().T
    return rho

def von_neumann_entropy(rho: np.ndarray) -> float:
    """
    Computes Von Neumann Entropy: S(rho) = -sum lambda_i * log2(lambda_i)
    """
    w = np.linalg.eigvalsh(rho)
    w = w[w > 1e-12]  # Remove zero eigenvalues
    w = w / np.sum(w)  # Ensure proper normalization
    return float(-np.sum(w * np.log2(w)))

def quantum_jensen_shannon_divergence(rho1: np.ndarray, rho2: np.ndarray) -> float:
    """
    Computes QJSD between two density matrices:
    QJSD = S((rho1 + rho2) / 2) - 0.5 * S(rho1) - 0.5 * S(rho2)
    Returns: value in [0.0, 1.0]
    """
    rho_mix = 0.5 * (rho1 + rho2)
    s_mix = von_neumann_entropy(rho_mix)
    s1 = von_neumann_entropy(rho1)
    s2 = von_neumann_entropy(rho2)
    qjsd = s_mix - 0.5 * s1 - 0.5 * s2
    return max(0.0, min(1.0, float(qjsd)))
```
