1. CORE MATHEMATICAL MECHANISM
--------------------------------------------------------------------------------
This landmark ICML paper explains why classical Graph Neural Networks (GNNs)
suffer from over-smoothing and proposes a physics-inspired solution based on
second-order wave/oscillator equations.

The Core Problem in Classical GNNs:
Standard message passing (e.g., GCN, GAT, GraphSAGE) is mathematically equivalent
to a first-order parabolic heat diffusion equation on graphs:
    dY/dt = -Delta_G Y = -(I - D^{-1/2} A D^{-1/2}) Y
As depth t -> infty, solutions exponentially converge to the kernel of the graph
Laplacian (the space of constant node embeddings). The Dirichlet energy:
    E(Y(t)) = 0.5 * Tr(Y(t)^T Delta_G Y(t)) -> 0  exponentially!
All nodes become identical, destroying fraud detection accuracy beyond 2-3 hops.

The Wave-Equation Alternative (GraphCON):
Instead of first-order heat diffusion, the authors model node features as a system
of second-order controlled, damped, coupled harmonic oscillators:
    d^2 Y / dt^2 + gamma * dY/dt + Y = F_theta(Y, A)
where gamma > 0 is a damping factor and F_theta is a graph coupling function.

Mathematical Proof of Over-Smoothing Immunity:
By casting the dynamics as a Hamiltonian/symplectic phase space system with
position Y and velocity V = dY/dt, the authors mathematically prove that:
The steady states with zero Dirichlet energy (E(Y) = 0) are UNSTABLE!
Oscillatory dynamics actively preserve high-frequency signals and keep node
representations distinct even at depths exceeding 50-100 layers.

import numpy as np

def compute_dirichlet_energy(node_features: np.ndarray, laplacian: np.ndarray) -> float:
    """
    Computes graph Dirichlet energy: E(X) = 0.5 * Tr(X^T L X)
    Measures degree of over-smoothing (E -> 0 indicates complete collapse).
    """
    return 0.5 * float(np.trace(node_features.T @ laplacian @ node_features))

def unitary_wave_feature_propagation(H: np.ndarray, initial_features: np.ndarray, 
                                     t_steps: list) -> np.ndarray:
    """
    Propagates node features using norm-preserving unitary wave evolution,
    guaranteeing that Dirichlet energy and feature variance do not collapse.
    """
    N = H.shape[0]
    w, V = np.linalg.eigh(H)
    propagated_features = []
    
    for t in t_steps:
        # Unitary propagation operator U(t) = V exp(-i * w * t) V^\dagger
        U_t = V @ np.diag(np.exp(-1j * w * t)) @ V.conj().T
        # Propagate features through wave operator
        X_t = U_t @ initial_features
        # Extract modulus (magnitude) to retain real-valued features
        X_mag = np.abs(X_t)
        propagated_features.append(X_mag)
        
    # Concatenate multi-scale wave features: (N, num_times * feature_dim)
    return np.hstack(propagated_features)
