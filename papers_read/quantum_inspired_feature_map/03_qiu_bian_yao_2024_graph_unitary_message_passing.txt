1. CORE MATHEMATICAL MECHANISM
--------------------------------------------------------------------------------
This paper identifies that training instability, gradient explosion/vanishing,
and over-smoothing in deep GNNs stem directly from the non-unitarity of the graph
propagation operator.

Theoretical Diagnosis:
In a message passing network X^{(l+1)} = sigma( P X^{(l)} W^{(l)} ), the singular
values of P determine the dynamics. For standard normalized adjacency matrices:
    sigma_1(P) = 1,  sigma_i(P) < 1 (for i >= 2)
As depth increases, any component in the orthogonal complement of the all-ones
vector is contracted exponentially, resulting in over-smoothing and over-squashing.

The GUMP Framework:
The authors formulate Graph Unitary Message Passing (GUMP) by enforcing the
propagation matrix P to be strictly unitary (or orthogonal for real networks):
    P^T P = I
To construct a valid graph-respecting unitary operator on arbitrary directed
graphs, GUMP uses:
1. An Eulerian Line Graph Construction (or Hamiltonian symmetrization): Mapping
   directed edges into a structure where in-degree equals out-degree.
2. Unitary Polar Decomposition / Newton-Schulz Iteration:
   Given an initial adjacency matrix A, the closest unitary matrix U is obtained via:
       U = A * (A^T A)^{-1/2}
   which can be computed efficiently via the iterative Newton-Schulz algorithm:
       X_0 = A / ||A||_2,  X_{k+1} = 0.5 * X_k * (3 * I - X_k^T X_k)

Benefits:
Because P is unitary, all singular values sigma_i(P) = 1. The spectrum does not
decay, allowing models to propagate information across 32, 64, or 128 layers
without degradation!


2. WHY CLASSICAL SYSTEMS FAIL ON THIS DYNAMIC
--------------------------------------------------------------------------------
1. Over-Squashing on Directed Bottlenecks:
   When stolen money moves from 20 accounts into 2 exit accounts, classical
   directed message passing creates an information bottleneck (over-squashing).
   Information from the source nodes is lost because the transfer Jacobian
   collapses.
2. Depth Penalty:
   In classical fraud detection, practitioners are forced to limit GNNs to 2
   hops because adding a 3rd or 4th layer actively reduces performance. This
   leaves 4-hop and 5-hop mule networks completely undetectable.

import numpy as np

def newton_schulz_unitary_projection(M: np.ndarray, num_iters: int = 5) -> np.ndarray:
    """
    Computes closest unitary/orthogonal matrix to M via Newton-Schulz iteration:
    X_{k+1} = 0.5 * X_k @ (3 * I - X_k^\dagger @ X_k)
    """
    # Normalize by spectral norm
    norm_est = np.linalg.norm(M, 2)
    if norm_est == 0:
        return np.eye(M.shape[0], dtype=M.dtype)
    X = M / norm_est
    I = np.eye(M.shape[0], dtype=M.dtype)
    
    for _ in range(num_iters):
        X = 0.5 * X @ (3.0 * I - X.conj().T @ X)
        
    return X

def compute_gump_propagation_jacobian_norm(P: np.ndarray, num_layers: int = 6) -> float:
    """
    Measures the preservation of signal norm across num_layers of propagation P^L:
    For unitary P, this is exactly 1.0; for standard GNN P, it decays to 0.
    """
    P_L = np.linalg.matrix_power(P, num_layers)
    singular_values = np.linalg.svd(P_L, compute_uv=False)
    # Return minimum singular value (for non-trivial subspace)
    return float(np.min(singular_values[singular_values > 1e-6]))
