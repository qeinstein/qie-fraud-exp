1. CORE MATHEMATICAL MECHANISM
--------------------------------------------------------------------------------
This foundational Physical Review Letters paper establishes the exact theoretical
equivalence between quantum machine learning algorithms and classical Kernel
Methods in Reproducing Kernel Hilbert Spaces (RKHS).

The Core Mathematical Unification:
Any quantum algorithm that encodes classical data x into a quantum state
|psi(x)> = U(x) |0> and measures an observable M:
    f(x) = <psi(x)| M |psi(x)> = Tr[ M |psi(x)><psi(x)| ]
is strictly equivalent to a linear model in a feature Hilbert space:
    f(x) = <w, Phi(x)>_H
where the feature map is Phi(x) = |psi(x)><psi(x)|, and the weight vector is w = M.

Representer Theorem in Quantum Spaces:
By the classical Representer Theorem, the optimal observable M_{opt} is an
expansion over the training data:
    M_{opt} = sum_{i=1}^m alpha_i |psi(x_i)><psi(x_i)|
The decision function becomes:
    f(x) = sum_{i=1}^m alpha_i |<psi(x_i)|psi(x)>|^2 = sum_{i=1}^m alpha_i K(x_i, x)
where K(x_i, x) is the quantum kernel.

Key Insight:
Quantum variational classifiers (VQC) and quantum neural networks are simply
kernel methods operating with an implicit quantum feature map. Designing a
quantum algorithm is mathematically equivalent to engineering a novel kernel!

```python
import numpy as np

def compute_schuld_spectral_kernel(H: np.ndarray) -> np.ndarray:
    """
    Computes Schuld-Killoran analytical infinite-time quantum walk kernel
    in closed form without numerical integration:
    K[u, v] = sum_k |V[u, k]|^2 * |V[v, k]|^2  (for non-degenerate H)
    """
    w, V = np.linalg.eigh(H)
    # V_mag_sq[u, k] = |V[u, k]|^2
    V_mag_sq = np.abs(V) ** 2
    # Matrix product yields K[u, v] = sum_k V_mag_sq[u, k] * V_mag_sq[v, k]
    K = V_mag_sq @ V_mag_sq.T
    
    # Normalize kernel matrix so diagonal is 1
    diag = np.sqrt(np.diag(K))
    K_norm = K / (np.outer(diag, diag) + 1e-12)
    return K_norm
```
